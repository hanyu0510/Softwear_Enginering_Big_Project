# 初步进度计划

按五周估算，课程截止日期明确后由组长换算实际日期。

| 阶段 | 主要任务 | 验收条件 |
| --- | --- | --- |
| 第 1 周 | 需求、草图、表结构、接口和真机媒体验证 | 确认基础功能和分工，上传播放链路可行 |
| 第 2 周 | 账号、文字发布、后台框架 | 登录发布后，后台能查到同一条内容 |
| 第 3 周 | 图片视频、标签日期筛选、互动和管理 | 两个用户和一个管理员能跑通基础场景 |
| 第 4 周 | 统计、过滤、跨端测试和修复 | 增强功能可验证，完成主要缺陷回归 |
| 第 5 周 | 部署、报告附件、答辩彩排 | 按运行说明可启动，交付目录完整 |

每位模块负责人随开发更新实现说明、自测记录和截图，成员 7 汇总，组长组织验收。
