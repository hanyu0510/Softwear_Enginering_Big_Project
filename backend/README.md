# 衣搭公共后端

账号、衣橱与社区使用同一 FastAPI 应用 app.main:app 和 DATABASE_URL。

运行：python -m pip install -r requirements.txt，然后 python run.py，打开 http://127.0.0.1:8002。

账号模块包含注册、登录、会话刷新、资料管理、原密码验证改密、课程版忘记密码、关注、通知与偏好。注册成功后需重新登录。

公共入口、数据库与认证兼容修复已完成本地 89 项回归测试。头像关联及我的帖子列表适配器仍待联调；完整说明随本次公共应用整合提交。

原社区作者和帖子数据会保留，演示作者不会自动获得登录凭据。忘记密码直接用邮箱重置，仅供本地课程验收。
