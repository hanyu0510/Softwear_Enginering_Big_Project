# 衣搭后端

此目录用于衣搭的 Python、FastAPI 和 SQLite 后端。首周计划接入演示登录、衣橱和收藏接口。

## 穿搭推荐联调模块

`recommendation/` 是可独立运行的推荐服务，包含真实天气、规则推荐、测试网页与 40 件商品/194 张图片的课程测试集。运行方法见 [recommendation/README.md](recommendation/README.md)。商品图片的使用范围见 [recommendation/fixtures/garment/README.md](recommendation/fixtures/garment/README.md)；图片不受本仓库 MIT 许可证约束。
