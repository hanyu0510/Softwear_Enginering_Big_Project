# 衣搭

衣搭是一款面向日常穿搭的响应式网页应用。第一阶段已完成邮箱认证、个人衣橱与社区基础互动，并提供课堂独立规则推荐与模拟识图。

## 平台功能

- **穿搭首页**：浏览带图片的穿搭内容，获得日常搭配灵感。
- **我的衣橱**：添加衣物并按类别整理，查看自己的衣物清单。
- **穿搭推荐**：浏览由上衣、下装、鞋包等单品组成的示例搭配。
- **社区互动**：支持点赞、帖子收藏及评论，个人收藏列表待联调。
