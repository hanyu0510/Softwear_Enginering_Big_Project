# 衣搭

衣搭是一款面向日常穿搭的移动端网页应用。你可以把常穿的衣物整理进个人衣橱，在挑选搭配时浏览示例方案，也可以把喜欢的搭配收藏起来，方便下次查看。

## 平台功能

- **穿搭首页**：浏览带图片的穿搭内容，获得日常搭配灵感。
- **我的衣橱**：添加衣物并按类别整理，查看自己的衣物清单。
- **穿搭推荐**：浏览由上衣、下装、鞋包等单品组成的示例搭配。
- **我的收藏**：保存喜欢的搭配，在个人页面集中查看。

## 第一周演示

项目目前处于课程原型开发阶段。第一周的目标是走通「演示账号登录 → 新增衣物 → 刷新后查看衣物 → 收藏搭配 → 在『我的』查看收藏」。注册、找回密码已制作前端页面，搭配推荐计划使用预设数据。

## 技术栈与代码目录

- `frontend/`：Vue 3、Vite、Vue Router 和 TDesign Mobile Vue，负责界面和交互。
- `backend/`：计划使用 Python、FastAPI 和 SQLite，负责接口及衣物、收藏等数据的保存。
