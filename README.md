# 拾光校园

软件工程课程项目。计划开发微信小程序和 Web 管理后台，支持校园多媒体动态发布、检索、评分评论和管理。

当前阶段为立项与仓库初始化。业务代码按下列目录逐步实现，技术方案拟采用微信原生小程序、Vue 3、Spring Boot 和 MySQL。

## 项目目录

| 目录 | 内容 |
| --- | --- |
| `miniprogram/` | 微信小程序 |
| `admin-web/` | Web 管理后台 |
| `backend/` | 后端服务 |
| `database/` | 表结构、迁移和可公开的演示数据 |
| `docs/` | 需求、设计、接口、分工、测试和课程资料 |
| `practice/` | 多人共同修改代码及冲突解决练习 |

## 开始协作

组长先在 GitHub 创建私有仓库并连接本地仓库，见 [远程仓库设置](docs/github-setup.md)。其余成员接受邀请后，从同一个远程仓库克隆项目，按 [协作指南](CONTRIBUTING.md) 提交各自的功能分支和 Pull Request。

`main` 保存验收通过的版本，`develop` 用于日常联调。成员从 `develop` 新建短期功能分支，完成后向 `develop` 提交 PR。每次提交应能说明作者做了什么。

## 课程协作要求

每位成员使用自己的 GitHub 账号推送。按 [冲突练习](practice/README.md) 共同修改同一个代码文件，并在 [协作记录](docs/collaboration-record.md) 中填写真实的提交、PR 和冲突解决证据。

## 交付材料

代码、实验报告、用户故事、产品功能设计、面向对象架构设计、白盒黑盒测试文档以及课堂汇报 PPT。课程提供的四份模板保存在 `docs/course-templates/`。项目运行步骤在模块可运行后补充至各模块 README。
