# 衣搭视觉设计规范

采用轻奢时尚杂志风。保留原创衣架字标、暖白背景、深暖棕交互、中文衬线主标题与系统无衬线正文。默认采用系统字体回退，课堂核心流程无需字体 CDN。 [正式样式](../src/style.css) · [品牌标志](../src/assets/yida-mark.svg)

| 角色 | 值与用法 |
| --- | --- |
| 背景和表面 | `--paper #f8f5ef`、白底与燕麦色。表单及卡片使用中性背景，资料区可使用燕麦色。 |
| 主操作 | `--brand #746354`、`--brand-pressed #5c4c40`。主入口使用暖棕实色，次操作用描边或文字。 |
| 内容与描边 | `--ink #292724`、`--muted #675d54`、`--line #dcd2c5`。交互边界采用更清晰的控件色。 |
| 反馈 | 以文字区分成功、失败、空态和待接入。错误保留重试入口，支持时显示请求编号。 |

- **导航与布局**　手机保留四项底栏和双列衣橱/信息流；768px 起平板可使用三列，1024px 起使用共用桌面侧栏。账号页保持独立导航。桌面首页按可用宽度调整列数；推荐、衣物详情与编辑、发帖及个人中心按阅读和编辑顺序组织双栏。
- **间距及图片**　沿用 4/8px 间距节奏、8px 卡片及 14px 面板圆角。信息流卡片预留图片比例，详情和拼贴尽量保留图片主体。课程摄影和服饰参考图注明来源范围，发布前需核对授权。
- **交互**　字段使用可见标签与错误提示。交互元素有键盘焦点，弹层支持 Escape 和焦点归还，排序提供按钮，用户选择减少动效时使用相应媒体查询。移动导航保留安全区。
