# 衣搭开发对齐文档 · 前端增补稿

供项目群讨论与联调。本文对照《开发对齐文档》第 2、3、4、5、6、7 节记录当前实现和待确认事项。数据库、业务字段、枚举、公共接口及团队分工沿用原文。

## 长期实现规范

- **技术栈与版面**　Vue 3、Vite、Vue Router（Hash 路由）、TDesign Mobile Vue 和 JavaScript。五个功能版面为账号、社区首页、穿搭推荐、衣橱、个人中心。发帖由首页及桌面侧栏进入同一页面。账号三页独立，登录后各业务子页继续使用返回栏。
- **导航与品牌**　移动用首页、推荐、衣橱、我的四项底栏。平板保留底栏，桌面从 1024px 使用共用侧栏及发布入口，各页面按图片、表单、资料区所需分别设定宽度。延用衣架字标、暖白、燕麦和深暖棕，使用系统字体、线性图标与本地样本。复用模板、可访问标签、键盘焦点和减少动效设置。
- **请求与认证**　公共接口统一走同源 `/api/v1`。封装区分 HTTP、业务、连接与主动取消，错误提示保留 `requestId`。Access Token 仅存 `sessionStorage`，刷新 Cookie 仅由后端签发并使用 HttpOnly。Bearer 跟随私有请求；并发 `40101` 共用刷新，原请求至多重试一次，认证入口避免回环，账号切换后丢弃旧请求与图片。注册后回登录；改邮箱保留会话；改密、找回以及退出按服务端结果清除身份。
- **字典与媒体**　登录后读取 `/me`、`/dict`、`/config`。季节、场合、风格按契约使用数组与多选；可见性、确认状态、保暖度使用真实值和字典。当颜色字典为空，衣物颜色按当前后端允许输入文本，颜色偏好依开关处理。衣橱上传压缩后获取 `fileId`，录入体使用 `imageFileId`，衣物 ID 用于详情与修改。授权图经 Bearer 请求获取 Blob，换图、卸载、换号时释放 URL。
- **反馈状态**　区分加载、空列表、连接异常、操作被拒和待接入。低质量图片显示明确占位，列表配置关闭时保留说明。页面切换和写入使用同一套用户与权限语义。

## 当前公共接口接入

| 范围 | 已接入与边界 |
| --- | --- |
| 账号和个人中心 | 注册、登录、刷新、退出、改密、找回；真实 `/me` 与资料修改，关注/粉丝数与列表、通知及偏好入口。头像关联及个人帖子、点赞、收藏列表依 `/config` 显示待接入。 |
| 社区 | `/posts` 排序分页、详情与多图；评论列表与录入，PUT/DELETE 点赞与帖子收藏。首页按登录区展示，游客交互待全组口径确认。搜索和写帖子暂未启用，公共 POST `/posts` 在实际验收返回 405。 |
| 衣橱 | 授权列表、总数、分类、搜索与筛选、上传、单品读取和修改、自有单品收藏。主界面可看心愿衣橱状态，心愿链路保留为后续集成。 |
| 发帖编辑 | 支持本机多图、调整顺序、删除和离开确认；已有 `title`、`text`、`post_type` 的预览编辑，标签仅用于预览。发布开关关闭，未发出上传或写帖子请求。 |

## 课堂演示临时运行

`demo/` 脚本以 `127.0.0.1` 统一启动前端 5173、公共 FastAPI 8002、独立规则推荐 8010。各副本从项目样本生成本地媒体、两个专用 SQLite 库及自己的课程账号。公共账号仍经真实注册和认证，课堂样本帖子和预置评论明确标注，实时互动调用公共 API。

独立推荐仅由 Vite 显式课程模式连接，代理移除公共 Bearer 与 Cookie，再由服务器端使用模拟身份。结果和天气标记来自样本衣橱与模拟天气，正式公共衣物暂未接入。模拟识图通过公共 FastAPI 的开发 provider 提供建议，修改和确认使用真实接口。正式构建关闭独立推荐、模拟素材和识图入口。服务异常可手动打开只读推荐样例。以上运行方式属于课堂配置。

Windows 用 `demo/setup-demo.bat` 或 `setup-demo.ps1` 首次初始化，再用 `start-demo` 和 `stop-demo`。macOS/Linux 从项目根目录执行 `sh demo/setup-demo.sh`、`sh demo/start-demo.sh`、`sh demo/stop-demo.sh`。先安装对应 Python、Node.js、npm。组员使用各自生成的凭据与数据。工具细节见 [课堂启动说明](../../demo/README.md)。

正式上线前须补足密码找回的账号所有权验证。现有找回流程用于隔离的课堂账号。

## 后续联调与验收

1. **社区写入**　依原文 §3.5、§5.4 确认 `POST /posts`、编辑和删除的注册、鉴权和字段。明确 `image_urls` 与 `post_images` 的上传、授权 URL、排序及缩略图语义，确认标签写入、字段/张数上限，以及仅本人公开单品的关联方式。接通后验证实际返回、真实入流、同时编辑、私密项拒绝与删除的媒体权限。由后端给出确定口径后，再替换本地预览中的发布禁用态。
2. **公共推荐和识图**　确认公共身份、已确认衣物与偏好数据适配，再启用正式服务。校验模型超时、真实来源、手动录入回退、确认后持久化和请求隔离。
3. **配置与跨模块**　核对头像上传用途和关联、个人帖子三列表适配器、颜色白名单、心愿口径、社区搜索和公开访问后再打开界面能力。按照原文 §7.1/§7.2，联调后复验登录刷新、退出、A/B 私密隔离、桌面与移动布局以及正式构建。
