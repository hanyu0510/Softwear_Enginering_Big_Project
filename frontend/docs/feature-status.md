# 第一阶段功能状态

| 类别 | 当前实现 |
| --- | --- |
| 真实公共接口 | 邮箱注册、登录、刷新、退出、资料及修改、字典和配置；社区读取、详情、多图、评论、点赞和帖子收藏；衣橱查询、筛选、图片上传、增改和自有单品收藏。 |
| 本地预览 | 发帖编辑、图片排序删除及离开确认。发布禁用，草稿与照片留在浏览器本次编辑会话。 |
| 课堂独立服务 | 规则推荐使用独立数据库的样本衣橱与模拟天气。前端明确展示来源，现场录入的真实公共衣物暂未纳入。 |
| 模拟识图 | 回环课堂模式使用开发 provider 返回识图建议；编辑和确认保存使用公共接口。 |
| 待联调 | 社区真实发帖、编辑、删除、公开关联和搜索；头像关联、个人三个列表、心愿衣橱；公共推荐、真实识图与可信天气。 |

正式部署前需补足密码找回的账号所有权验证。现有课程找回流程适用于隔离的演示账号。跨模块验收应覆盖跨账号授权、媒体权限、会话刷新、独立数据来源及降级说明。 [前端开发对齐文档增补](frontend-contract-supplement.md)
